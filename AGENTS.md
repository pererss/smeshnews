# SMESH Forwarder — заметки для агента

## Правило ответов (запрос пользователя)

В конце каждого ответа всегда давать:

1. **Команды**, которые нужно выполнить (в блоке кода).
2. **Вывод** — что эти команды должны показать.

## Проект

- Запуск бота: `python main.py`
- Тесты: `python -m unittest discover -s tests`
- Линтер: `python -m ruff check .`
- Установка зависимостей: `pip install -r requirements.txt`
- Секреты и ключи — только в `.env`, токен в логи не выводится.
- Маршруты настраиваются в боте кнопками; `config.json` меняется только программой.
- Три способа чтения источника: бот-админ (`via: bot`), публичная веб-страница (`via: preview`), аккаунт пользователя (`via: account`, необязательный).

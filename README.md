# 📰 SMESH Forwarder — пересылка из канала в канал

Бот берёт новые сообщения из одного канала и отправляет их в другой.

Пример: из `@toporlive` → в `@smesh_news`.

Всё настраивается в боте кнопками. В файлах ничего писать не надо (кроме токена и ID — один раз).

---

## ⚠️ Самое важное — прочитай 1 минуту

Обычный Telegram-бот видит сообщения только тех каналов, где он администратор. Но читать источник можно тремя способами:

1. **Канал твой** → добавь бота админом. Работает мгновенно.
2. **Канал чужой, но публичный** → просто напиши его `@username` в боте. Бот сам будет читать канал через публичную веб-страницу `t.me`. Добавлять бота никуда не надо, ключи тоже не нужны. Новые посты появляются с задержкой до 20 секунд.
3. **Канал чужой и приватный** → так нельзя: приватные каналы без доступа не читает никто.

Режим «от твоего аккаунта» (для опытных, нужны ключи с my.telegram.org) — необязательный, описан ниже.

---

## Публичные каналы без бота (веб-режим)

Если бот не админ в канале, но канал **публичный**, ничего настраивать не нужно:

1. В боте: `/start` → **«➕ Добавить маршрут»**.
2. Напиши `@toporlive` (или любой публичный канал).
3. Напиши свой канал и нажми «✅ Создать».

Бот сам поймёт, что это чужой канал, и будет читать его веб-версию. В карточке маршрута будет написано **«Читаю: веб-страница»**.

Что важно знать:

- Новые посты появляются с задержкой **до 20 секунд**.
- Отправляются текст, фото и видео. Документы, голосовые и стикеры — если у них нет прямой ссылки, приходит подпись со ссылкой на пост.
- Если Telegram не может скачать файл по ссылке (ошибка «failed to get HTTP URL content»), бот скачивает файл сам и загружает его в канал — это работает автоматически.
- Если канал публикует очень часто (больше 20 постов за 20 секунд), часть старых может пропуститься.
- Если в канале запрещено сохранение контента — пересылки не будет.
- Работает только для публичных каналов с `@username`. Приватные так читать нельзя.

## Режим «от твоего аккаунта» (необязательно)

Этот режим нужен, только если хочется читать канал мгновенно или канал не публичный, но ты на него подписан. Для публичных каналов проще веб-режим выше — ключи не нужны.

Это когда бот не может войти в чужой канал, но ты сам на него подписан.

**Что нужно один раз сделать:**

1. Открой официальный сайт Telegram: https://my.telegram.org
2. Войди по своему номеру телефона (код придёт в Telegram).
3. Нажми **«API development tools»**.
4. Заполни название приложения (любое, например `smesh`) и нажми создать.
5. Появятся два значения: **API_ID** (число) и **API_HASH** (набор букв и цифр).
6. Добавь их в конец файла `.env`:

```env
API_ID=1234567
API_HASH=abcdef1234567890abcdef1234567890
PHONE=+79991234567
```

`PHONE` — твой номер телефона, с `+` и без пробелов.

7. Запусти `python main.py`. **В первый раз** Telegram пришлёт в приложение код — введи его в чёрное окно. Больше код спрашивать не будет: вход сохранится в файл `userbot.session`.

Если Telegram не открывается напрямую (таймаут) — включи VPN или укажи `PROXY_URL` в `.env`: он работает и для этого режима.

**Как пользоваться:**

Всё как обычно: `/start` → **«➕ Добавить маршрут»** → напиши чужой канал (например `@toporlive`) → напиши свой канал → «✅ Создать».

Что важно знать:

- Твой аккаунт должен быть **подписан** на канал-источник (иначе бот его не увидит).
- Бот должен быть **админом** в канале, КУДА отправлять, с правом «Публикация сообщений».
- Не используй это для спама: Telegram может ограничить аккаунт.
- Файл `userbot.session` — это доступ к твоему аккаунту. Никому не передавай и не выкладывай.
- Файлы больше 50 МБ бот отправить не может — они будут пропущены с уведомлением.
- Если в чужом канале включён запрет сохранения контента — пересылки не будет. Это правило Telegram, бот его не обходит.
- Этот режим необязательный: без `API_ID`/`API_HASH` бот работает как раньше — читает каналы, где он админ.

## Что понадобится (один раз)

1. **Python 3.10 или новее** — программа, на которой работает бот.
2. **Токен бота** — его выдаёт @BotFather в Telegram.
3. **Твой Telegram ID** — число, его показывает @userinfobot.

---

## Шаг 1. Установи Python

**Windows:** скачай с https://www.python.org/downloads/ и при установке поставь галочку **«Add Python to PATH»**.

**macOS:** `brew install python`

**Linux:** `sudo apt install python3 python3-venv python3-pip`

Проверка (в командной строке): `python --version` — должно быть 3.10 или больше.

---

## Шаг 2. Создай бота

1. В Telegram открой **@BotFather**.
2. Напиши `/newbot`.
3. Придумай имя бота (любое).
4. Придумай username, он должен заканчиваться на `bot` (например `smesh_forwarder_bot`).
5. BotFather пришлёт токен вида `1234567890:AAH...`. Скопируй его.

> Токен — это пароль от бота. Никому не показывай.

---

## Шаг 3. Заполни файл .env

В папке проекта есть файл `.env.example`. Скопируй его в `.env`:

**Windows:**
```powershell
Copy-Item .env.example .env
```

**macOS/Linux:**
```bash
cp .env.example .env
```

Открой `.env` блокнотом и заполни **две строки**:

```env
BOT_TOKEN=сюда_токен_из_BotFather
ADMIN_ID=сюда_твой_номер_из_userinfobot
```

Сохрани. Больше в этом файле ничего писать не нужно.

---

## Шаг 4. Установи программы-помощники

В командной строке, в папке проекта:

**Windows:**
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

---

## Шаг 5. Запусти

```bash
python main.py
```

Если увидел:

```
[INFO] Бот запущен: @твой_бот
```

— всё хорошо. Если увидел «Не удалось подключиться к Telegram» — это блокировка интернета, смотри раздел «Если не подключается» ниже.

## Как настроить пересылку (только кнопками в боте)

1. **Добавь бота админом** в канал, ОТКУДА брать сообщения.
2. **Добавь бота админом** в канал, КУДА отправлять. Там же включи боту право **«Публикация сообщений»**.
3. Открой бота в Telegram и напиши `/start`.
4. Нажми **«➕ Добавить маршрут»**.
5. Напиши канал ОТКУДА, например: `@toporlive`
6. Напиши канал КУДА, например: `@smesh_news`
7. Нажми **«✅ Создать»**.

Готово! Теперь всё новое из первого канала будет появляться во втором.

Хочешь ещё одну пересылку — повтори шаги 4–7.

## Кнопки в боте — что делают

| Кнопка | Что делает |
|---|---|
| 📡 Источники | Показывает каналы, откуда бот берёт сообщения. Тут можно выключить/включить канал или удалить его. |
| 🔀 Маршруты | Показывает все пересылки «ОТКУДА → КУДА». Каждую можно включить, выключить, изменить или удалить. |
| ➕ Добавить маршрут | Добавить новую пересылку. |
| ➖ Удалить маршрут | Удалить пересылку (спросит подтверждение). |
| ▶️ Запустить | Включить пересылку, если была пауза. |
| ⏸ Остановить | Пауза для всех пересылок. Настройки не удаляются. |
| 📊 Статус | Сколько сообщений пришло и ушло, сколько ошибок, сколько бот работает. |
| ⚙️ Настройки | Оформление (со ссылкой на источник или без), уведомления об ошибках, задержка. |

Если нажать «Назад» или «Отмена» — ничего не сломается, просто вернёшься в меню.

## Настройки — простыми словами

| Настройка | Что значит |
|---|---|
| 📝 Оформление | «пересылка» — в канале КУДА видно, что сообщение переслано. «копия» — выглядит как обычное сообщение, без ссылки на источник. |
| 🔔 Уведомления об ошибках | Если что-то не отправилось — бот напишет тебе в личку. Ошибки в любом случае пишутся в лог. |
| ⏱ Задержка | Пауза перед отправкой: 0, 1, 3 или 5 секунд. Обычно нужна 0. |

## Если сообщения не приходят

Проверь по порядку:

1. В боте не стоит «⏸ Остановить»? Открой **📊 Статус**.
2. Маршрут включён? **🔀 Маршруты** → должно быть «🟢 Включён».
3. Бот админ в канале ОТКУДА? Без этого Telegram не даёт ему сообщения.
4. Бот админ в канале КУДА и у него есть право «Публикация сообщений»?
5. Канал переименовали? Тогда удали маршрут и добавь заново с новым @username.
6. В канале ОТКУДА включён «запрет сохранения контента»? Тогда Telegram запрещает пересылку — это ограничение Telegram (смотри ниже).
7. Посмотри чёрное окно, где запущен бот: там написана причина ошибки. И бот пришлёт тебе сообщение в личку, если уведомления включены.

---

## Если не подключается к Telegram (таймаут)

Если при запуске пишет «Не удалось подключиться к Telegram» — значит, твой интернет или провайдер блокирует `api.telegram.org`. Сам бот тут ни при чём.

Что делать:

1. **Включи VPN** и запусти `python main.py` снова.
2. Или укажи прокси. Для этого в конец файла `.env` добавь строку:

```env
PROXY_URL=http://логин:пароль@адрес:порт
```

Если у прокси нет логина и пароля: `PROXY_URL=http://адрес:порт`.

После этого один раз выполни `pip install -r requirements.txt` (там есть нужная библиотека для прокси).

## Ограничения Telegram (это нельзя обойти)

1. **Бот видит канал только если он там администратор.** Чужой канал без согласия владельца читать нельзя.
2. **Защищённый контент.** Если в канале включён запрет сохранения, Telegram не разрешает ни пересылать, ни копировать. Бот напишет об этом тебе и в лог и продолжит работать.
3. **Платные сообщения** пересылать нельзя.
4. **Альбомы.** Отдельной кнопки «переслать альбом» в Telegram нет. В режиме «пересылка» фото уходят по одному, в режиме «копия» бот собирает альбом заново.
5. **Старые сообщения.** Бот видит только новые сообщения. Если он был выключен больше суток — пропущенные не придут.
6. **Ссылки-приглашения** вида `t.me/+...` не подходят. Нужен `@username` или ID вида `-100...`.
7. **Скорость.** Если отправлять слишком часто, Telegram просит подождать — бот подождёт и продолжит.

## Как остановить бота

- Нажми `Ctrl + C` в чёрном окне, где он запущен.
- Или в боте нажми **«⏸ Остановить»** — бот останется включённым, но пересылать не будет. Кнопка **«▶️ Запустить»** включит обратно.

---

## Как запустить, чтобы работал всегда

**Linux:** создай службу systemd (файл `/etc/systemd/system/smesh-forwarder.service`):

```ini
[Unit]
Description=SMESH Forwarder
After=network-online.target
Wants=network-online.target

[Service]
WorkingDirectory=/opt/smeshbot
ExecStart=/opt/smeshbot/.venv/bin/python /opt/smeshbot/main.py
Restart=always
RestartSec=5
User=www-data

[Install]
WantedBy=multi-user.target
```

Затем: `sudo systemctl daemon-reload && sudo systemctl enable --now smesh-forwarder`

**Windows:** «Планировщик заданий» → задача «При запуске компьютера» → программа `python.exe` из папки `.venv`, аргумент `main.py`, рабочая папка — папка проекта.

## Частые вопросы

**Нужна база данных?** Нет. Всё в `config.json`.

**После перезапуска всё пропадёт?** Нет. Маршруты и настройки сохраняются.

**Сообщение отправится два раза?** Нет, бот запоминает последнее отправленное.

**Один маршрут сломался — остальные встанут?** Нет, каждый маршрут работает отдельно.
